Tic-Tac-Toe Game

Welcome to the Tic-Tac-Toe Game repository! 🕹️

Overview

A simple console-based Tic-Tac-Toe game implemented in C++. Play against another player using a command-line interface.

Features

Two-Player Mode: Play against another player on the same computer.

Interactive Board: Uses characters to display the game board and capture player input.

Code Highlights

Character Functions

Display Board: Uses char to represent X, O, and empty spaces on the game board.

Player Input: Captures player input and updates the board.

Uses a function to iterate through the possible moves.

Loops

Game Loop: Uses a for loop to keep the game running until a player wins or the board is full.

Technologies

Language: C++

Compiler: Any standard C++ compiler (e.g., g++, clang++)
